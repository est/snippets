JS 能测鼠标轮询率吗？触摸屏刷新呢？

浏览器没有官方 API 直接读 HID polling rate 或触控面板采样率。 只能用事件时间戳差分来估算：相邻 pointermove / mousemove / touchmove 的间隔 → Hz。浏览器常会把多次采样合成一次事件，所以再对比 getCoalescedEvents() 和屏幕的 requestAnimationFrame。

怎么读结果

  • Mouse Hz ≈ 鼠标回报率的上限，但常被浏览器对齐到显示器刷新（很多桌面 Chrome 上你会看到 ~60 / 120 / 144，而不是 1000）。勾选 coalesced 后，若驱动/浏览器保留了中间采样，数字会往真实 polling 靠。
  • Touch Hz 是触控采样经浏览器投递后的频率，常见 60–120，部分高刷屏/游戏机可达 240。这不是 LCD 刷新率本身；右边 rAF 才更接近屏幕刷新。
  • screen.refreshRate / Window Management 的 refreshRate 只有少数环境会给。本页会显示有没有。
  • 估算取最近窗口的中位数间隔的倒数，比瞬时 1/Δt 稳。样本少时不要当真。
