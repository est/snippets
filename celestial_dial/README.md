# Celestial Dial — 地心说

> 拖拽月亮一圈≈1月，拖拽太阳一圈≈1年，拖拽岁星一圈≈12年。右下角地心圆盘，联动全屏行星轨道。尽可能贴近天文学常数，零依赖单页。

在线打开：`celestial_dial/index.html`（GitHub Pages 自动发布）

---

## 概念

地心说（Geocentric）只是 UI 隐喻：地球居中，三层同心轨道分别对应三档时间尺度。不是要复刻托勒密本轮均轮——而是借“天体一圈即一周期”的直觉，把滚动条换成可拨动的星盘。

- **🌙 月亮** — 内圈，360° = 1 朔望月 29.53059 天。月相随相位实时切换：🌑🌒🌓🌔🌕🌖🌗🌘。
- **☀️ 太阳** — 中圈，360° = 1 回归年 365.24219 天。12 刻度对应公历 1–12 月。
- **♃ 岁星（木星）** — 外圈，360° = 1 恒星周期 4332.589 天 ≈ 11.862 年，文案写作“约 12 年一纪”，与中式十二地支（子丑寅卯…）对齐。

> 三档叠加到同一连续时间轴上，真正可用 12 年尺度“一眼看完一个朝代”。

## 怎么玩

- **拖拽圆盘指柄** — 命中哪根就以哪档精度拨动时间；指柄吸附与光晕提示当前档位。
- **滚轮** — 在圆盘上滚动缩放背景轨道（55%–145%）。
- **方向键** — ←/→ 按天，↑/↓ 按月；Shift 加速，Alt 按年。
- **流动** — 右上角 ▶ 流动，时间自动前进；可点 `×1` 切换 0.5× / 1× / 3× / 8× / 20×。
- **今天 / 随机一天** — 跳转到今日或随机历史事件附近。
- **轨道背景** — 全屏 Canvas，8 大行星在各自轨道上实时运动；太阳居中发光，土星带环。

## 天文常数（拟真等级）

| 量 | 取值 | 来源/备注 |
|---|---|---|
| 朔望月 | 29.53058867 d | NEW_MOON_EPOCH 2451550.26（2000-01-06 18:14 UTC）起算 |
| 回归年 | 365.24219 d | 圆盘太阳圈与公历换算共用 |
| 木星恒星周期 | 4332.589 d = 11.862 y | 岁星外圈；文案“12 年”仅为中式纪年的取整 |
| 行星平运动 | `θ = M0 + 360·(JD-J2000)/period` | 背景轨道用圆轨道近似，足够演示拟真；精确椭圆可在 `PLANETS` 中加入偏心率后以牛顿迭代解开普勒方程升级 |

内部统一用**儒略日数 JD**连续计时，公历↔JD 用 Meeus 算法，支持 BCE（天文年计数，无公元 0 年问题；展示层再转“公元前/公元”）。闰年、大小月由 JD↔公历互转自然处理，不存在“月圈在 2 月失真”的离散跳变。

## 圆盘（地心说控件）

- SVG 三同心圆，中心 🌍，内中外半径 58 / 102 / 142（viewBox 320）。
- 刻度：月圈 30 刻（5 日一长刻）、日圈 12 月刻、岁星圈 12 地支刻。
- 指柄：直线 + 光晕圆 + emoji（月相动态），`pointerdown/move/up` 统一走 `pointerAngle → Δθ → Δdays = Δθ/360·period → JD += Δdays`。
- 跨 0° 跳变用 `unwrap`（Δθ 归一到 ±180°），可连续转多圈累积。
- 悬停与拖拽时显示 Tip：当前档位与增量（如 `♃ +0.123 年`）。

## 背景轨道

- Canvas 全屏，星点 260 颗微闪烁，太阳径向渐变光晕。
- 8 行星参数表 `a (AU), period (d), color, r`，显示半径用非线性映射 `sqrt(a)` 压缩（否则海王星 30 AU 会把内行星挤成点），并随 `zoom` 线性缩放。
- 行星角位置与圆盘岁星同源：`angle = (JD-J2000)/period·360°`，保证拨动岁星时木星与背景木星同步。
- 轨道线：地/木用实线加亮，其余虚线/淡线，土星附加椭圆环。

## 已知近似

- 月圈按朔望月连续天数拨动，不等于“公历月 +1”；文案已写“≈1 月”。
- 太阳圈零点取当年 1 月 1 日（贴公历直觉），而非春分点；如需更天文可在 `jdnToDialAngles` 中改历元。
- 背景行星为圆轨道近似，未计偏心率与摄动；拟真展示足够，科学级可在 `orbits` 区加入 `e, M0, ω` 并解 `E - e·sinE = M`。
- 干支按 `1984 = 甲子` 推算，仅示意；帝王纪年未接入。
